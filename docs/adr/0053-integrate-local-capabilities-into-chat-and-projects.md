# Integrate local capabilities into chat and Projects

Date: 2026-11-22

Status: Accepted

This extends [managed inference](0048-add-managed-local-inference-and-document-retrieval.md), [task discovery](0051-expand-small-model-discovery-by-task.md), and [Project context](0045-add-projects-and-independent-context-snapshots.md).

The product distinguishes answer models, processing tools, and source scope. The existing model selector retains Provider identity and offers an On this Mac management entry. Settings groups installed capabilities and discovery under On this Mac. Installing Qwen never silently changes the Active Model Set; Use in this chat explicitly selects its managed target after the catalog is available. The experimental quality description remains visible. BGE is presented as document search, with its engine identity in the details. Capabilities share the existing artifact registry and files.

The composer Tools menu opens local document search directly, including a separate current-Project scope. Missing BGE can be installed inside that dialog without replacing the draft or leaving the task. Users choose documents, inspect original sections, copy selected text independently, or attach selected source snapshots. Tools are explicit Cove actions and do not depend on the answer model implementing function calling. OCR, speech, and other discovery records remain explore-only until their runtimes and acceptance checks are implemented.

Project materials gain an explicit use: Always include or Search when needed. Existing materials default to Always include, preserving earlier behavior. Search-only materials stay outside the automatically rendered Project Context Snapshot. Their source originals remain in Project blob storage, with separate versioned vector indexes rather than a second global-library copy. Search covers explicitly selected materials in one Project. Source-use changes require the current Project revision, clear that index, and invalidate pending retrieval tokens. Removal also invalidates pending tokens; deleting a Project cascades its indexes. Selected Project passages carry Project identity and cannot be submitted as fresh attachments to a conversation outside that Project. Saved source copies remain independently owned by the accepted Batch. The existing total of three project materials and 60,000 extracted characters remains unchanged, reserving room for turn attachments.

The composer separately identifies local search and each answer destination. Only on this Mac is an explicit window-local sending restriction, shared with answer-tool sends. Enabling it turns off Web search and blocks external webpage preparation, including pending draft reads. Cloud model catalogs are not queried while this restriction is enabled. The server rejects remote targets or Web Research before Provider resolution, accepts only managed local chat targets, and saves the policy with the Batch. Retries preserve it; copied historical Batches preserve their recorded policy. The UI preserves the draft on incompatible selection and offers local-model setup. No remote fallback is introduced. Explicit model downloads still require network access; the restriction governs inference and processing for the chat, not downloads or previously running Debate sessions.

SQLite schema 26 adds the source-use field, Project vector indexes, and the Batch execution policy. Existing frozen Project payloads are not rewritten. Migration failures roll back. Clearing chat history removes global library records and all vector indexes while retaining live Project materials and installed weights. Removing BGE removes both global and Project indexes while preserving originals. This refines the deletion scope in [ADR-0052](0052-combine-projects-and-local-model-storage-migrations.md). Older services reject the newer schema.

Validation covers source-use migration and rollback, unchanged frozen payloads, scoped retrieval and source fidelity, stale revisions, cross-Project token rejection, policy rejection before Provider contact, saved local-only policy, draft preservation during in-place installation, and tools/management navigation. Real native inference and production WebUI checks complement these regressions.
