# Keep history search and draft navigation local

History search goes through the authenticated HTTP adapter, Chat query facade, and SQLite persistence. It matches literal case-insensitive substrings in titles and saved user/assistant bodies, including Unicode content, without loading all conversation bodies into the browser or contacting Providers. A query is limited to 256 characters, 50 matching conversations, and a three-second deadline. Results contain bounded excerpts and message references for turn navigation. The active/archived filter remains explicit. The initial scan-only implementation used a Unicode-aware SQLite scalar function. [ADR-0031](0031-index-local-history-substring-search.md) supersedes that implementation choice with a local trigram index while retaining literal verification and short-query scans.

Unsent text and attachment selections remain in memory. Conversation switches, creation, and archive navigation ask before discarding a draft. Cancelling preserves it, while confirmed active-Generation navigation retains the existing cancellation-before-switch ordering. Failed cancellation prevents navigation. Confirmed navigation keeps its dialog open while pending, and the composer blocks edits until creation finishes; creation failure retains the draft. Launcher intents use the same guard, and browser navigation uses the native unload confirmation where supported. This extends the presentation-state ownership in ADR-0019 without introducing persistent draft storage.

Markdown exports project comparison dispositions at export time and group available completed answers with their originating user turn. A read-only `selected_answer` summary identifies the saved Generation, assistant message, Provider name, and model even when a Target's latest retry has changed. Saved assistant messages also expose their read-only `generation_batch_id`, derived from the existing Generation relation, so older unselected attempts remain grouped with their original turn. These summaries add no persisted conversation data or mutation. Exports preserve the immutable Context Snapshot semantics in ADR-0015; a displayed Selected Answer does not imply every later Generation used it.
