# Cove 0.1.0-beta.2

The second public beta adds file chat, more predictable Keychain authorization, clearer Provider errors, and Cove's blue and teal wave identity.

## Download and install

- Requires an Apple Silicon Mac and macOS 13 or later. Intel Macs are not supported by this package.
- Download `Cove-0.1.0-beta.2-arm64.dmg`, open it, and drag `Cove.app` to Applications.
- Quit an earlier Cove instance before replacing the app, then launch Cove from Applications.
- The package is Developer ID signed and Apple notarized. Verify the download with the accompanying SHA-256 file when needed.
- Existing Cove history, settings, and Provider configuration are retained. Provider Keys continue to use macOS Keychain.

See the [user guide](../user-guide.md) for setup and daily use.

## New in this beta

- Attach UTF-8 text, Markdown, code, and text-based PDFs. Preview extracted text before sending, inspect Provider context, and open source citations at saved lines or pages.
- Save immutable source snapshots with each submitted turn. Comparisons and retries use the same saved input; selected earlier answers retain their attached source context.
- Download original attached files locally. Markdown and JSON exports include extracted text and source metadata, while original bytes remain outside exports.
- Reuse authorized Provider Key reads within a running Local Service and coalesce concurrent reads. Provider catalogs no longer automatically retry after focus or reconnect events that could reopen authorization dialogs.
- Detect failed or incomplete Gateway Responses streams before receipt lookup and show bounded upstream explanations instead of misleading cryptographic verification errors.
- Use the shared wave mark in the Chat Surface, browser favicon, macOS app icon, and menu bar.
- Resolve menu-bar resources from the installed app so startup does not depend on the original build machine.
- Expand the README, user guide, and product website with current setup, file chat, and beta update information.

## Compatibility and beta notes

- File chat supports up to four files per turn, each at most 4 MiB. Text extraction is bounded; scanned-only PDFs require OCR first. See the user guide for complete limits.
- Original files and extracted text are stored unencrypted in the local SQLite database. Providers receive extracted text through the selected transport. Citations navigate saved sources and do not independently verify an answer.
- SQLite schema 14 preserves earlier Cove history. Keep a backup before trying older app versions against newer data.
- A Provider Key changed outside the running Local Service may require restarting Cove before the new value is used. Switching signing identities can still require one-time macOS authorization.
- The interface remains English. Messages, titles, and prompts support Unicode content.
- The NearAI preset currently uses its staging service. Availability and verification support depend on the selected model and Provider.
- Download beta updates from GitHub Releases. The app's Check for Updates action follows the stable channel, which becomes available with the first stable release.
- Report reproducible problems through GitHub Issues or discuss setup in the [Cove Discord community](https://discord.gg/7jdddhG8ZG). Remove keys, launch URLs, and private content from diagnostics.
