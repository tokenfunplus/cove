# Cove 0.1.0-beta.6

The sixth public beta adds continuous multi-model Debate sessions, a focused debate reading view, and filters for local conversation history. It also improves Provider setup and hardens Pause, Stop, verification settlement, and storage recovery.

## Download and install

- Requires an Apple Silicon Mac and macOS 13 or later.
- Download `Cove-0.1.0-beta.6-arm64.dmg`, quit Cove, open the DMG, and drag `Cove.app` to Applications before relaunching.
- The published package is Developer ID signed and Apple notarized. A SHA-256 checksum accompanies the download; detached publisher signatures are added after publication.
- This is build `6`, with marketing version `0.1.0`. Existing history, attachments, settings, and Provider Profiles migrate in place. Provider Keys continue to use macOS Keychain.

See the [user guide](../user-guide.md), [Debate guide](../debate.md), [privacy model](../privacy.md), and [signature verification instructions](../releasing.md#detached-release-signatures).

## New in this beta

- Start a Debate with a topic, two to four Provider/model seats, distinct roles, and ground rules. Independent opening positions are followed by rotating turns, attributed checkpoints, and saved transcript exports. Discussion continues until you pause or stop it; agreement does not end the session.
- Use **Pause**, **Step**, **Resume**, and **Stop** to control model calls. Add an intervention or update ground rules for the next round. Checkpoints retain references to original turns rather than declaring an automatic winner.
- Include configured NearAI models through the existing browser encryption and verification transport. Exclusive claims prevent multiple tabs from executing the same scheduled turn, and completed browser turns retain verification details.
- Enter Debate **Focus** to give the transcript the main visual space, with participant activity, larger turn cards, and an on-demand live brief. Controls, intervention drafts, and reading position are preserved when switching views.
- Filter local history by activity period and conversation type. Search combines with the selected filters, preferences persist in the browser, and Debate rows show their current state and round in active and archived history.
- Start new Provider setup with a blank OpenAI-compatible connection. Changing connection type clears stale identity, endpoint, credential draft, model catalog, and connection-test state. Model selection uses the available width, and expired local authorization explains how to reopen Chat.

## Reliability improvements

- Manual and automatic pauses reject unclaimed browser work and releases its reservation; requests already claimed may finish. Stop remains terminal, cancels active work, and rejects late results. Shutdown closes admission before draining requests.
- Browser results accepted before their fixed deadline are saved even if expiry becomes ready at the same time. Failed verification cannot add an answer to later debate context.
- Storage failures cancel scheduling and reconcile unfinished attempts against the committed cursor. Unsaved answers do not advance completed-turn counts or skip seats, and recovery cannot make a stopped session resumable.
- Accepted interventions remain idempotent beyond the history read window. Every newly effective intervention reserves context space before older discussion history.
- Checkpoint inspections load full browser evidence. Stale detail requests cannot replace a newer selection or reopen a closed dialog, and Challenge cannot replace an intervention draft while it is being submitted.

## Compatibility and beta notes

- First launch upgrades schema 19 to schema 20 for Debate session, turn, and intervention records. Older Cove builds cannot open the upgraded database. Preserve a compatible backup before upgrading if downgrade may be needed; database backups do not include Keychain credentials.
- A running Debate reserves the same active-work slot as ordinary chat generation. Debate turns remain separate from ordinary Selected Answer context. History search currently matches Debate titles, not Debate turn bodies.
- Service-driven models can continue debating while the browser is closed. NearAI participation requires the Debate page to remain open for encryption and verification. Missing browser work or a Provider failure pauses the session; restart also leaves sessions paused. Resume is explicit, with no automatic Provider retry.
- Model calls use your configured Provider Keys and can incur Provider charges while a Debate runs. Each turn has bounded context, a request timeout, and an output token limit; there is no fixed session round limit.
- Verification records preserve the existing browser-reported trust boundary. Checkpoints are attributed excerpts, not proof that participants' claims are true. NearAI continues to use its staging endpoint.
- Local history and attachments remain unencrypted in SQLite. The interface is English, and user messages and topics support Unicode. Reopen Chat from the Launcher after upgrading to obtain a new Browser Session.
- **Check for Updates** stays on the stable channel. **Check for Beta Updates** explicitly discovers newer eligible prereleases; neither action installs an update.

Report reproducible issues through [GitHub Issues](https://github.com/tokenfunplus/cove/issues), removing credentials, launch URLs, and personal conversation data.
