# Cove 0.1.0-beta.12

Beta 12 adds Ask Cove to macOS Services and makes local PDF search results easier to review. The Continuum welcome ribbon now animates while visible and respects Reduce Motion.

## Ask Cove about selected text

- Select text in an app such as TextEdit and choose **Services > Ask Cove**. The selection opens in the Quick Panel as an editable draft.
- If a draft or conversation is already open, choose **Add to Current Draft**, **Start New Draft**, or **Dismiss**. A selection received during an answer waits until the answer finishes.
- Review the model destination and click **Send** when ready. To use an installed local model, choose **Tools > Only on this Mac** before sending.

See the [Ask Cove guide](../user-guide.md#ask-cove-about-selected-text).

## Review local document search results

- Search and selection controls stay visible as you scroll through compact excerpts. Open **View cited source sections** to inspect the full passage before copying it or adding it to a draft.
- Cove reconstructs clearly horizontal text that some PDFs store as individual characters. Results keep their original page references.
- Update an older PDF index in the document library to reprocess its saved original. Searchable Project PDFs update when searched. Saved conversations keep their original cited passages.

See the [local document search guide](../user-guide.md#use-local-capabilities-in-a-chat) and the [search results screenshot](../images/local-document-search-results.png).

## Download and upgrade

- Requires an Apple Silicon Mac with macOS 13 or later. Local inference and speech require macOS 13.3 or later.
- Download `Cove-0.1.0-beta.12-arm64.dmg`. Quit Cove, open the disk image, drag Cove to Applications, and relaunch it.
- This is build `12`, with marketing version `0.1.0`. SQLite migrates to schema 28. Earlier builds cannot open the upgraded database. Quit Cove and keep a compatible backup before upgrading if you plan to return to an earlier build.
- Choose **Check for Updates > Check Beta Releases…** to discover this prerelease. Verify the download using its SHA-256 checksum and [detached publisher signatures](../releasing.md#detached-release-signatures).
