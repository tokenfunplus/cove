# Cove 0.1.0-beta.1

The first beta of Cove, a local-first Mac AI chat application with on-device conversation history and verifiable NearAI inference.

## Download and install

- Requires an Apple Silicon Mac and macOS 13 or later. Intel Macs are not supported by this package.
- Download `Cove-0.1.0-beta.1-arm64.dmg`, open it, and drag `Cove.app` to Applications.
- Open Cove from Applications. The menu-bar Launcher starts its local service and opens the chat workspace in your browser.
- Configure your Provider and API key in Settings. Provider Keys are stored in macOS Keychain; conversation history stays on your Mac.

This package is Developer ID signed and Apple notarized. A SHA-256 checksum file is provided alongside the DMG.

## Included in this beta

- Streaming chat with OpenAI-compatible Providers and the NearAI preset.
- Comparisons across up to four model targets, with explicit answer selection for later context.
- Saved verification evidence, direct verification shortcuts, and the embedded NearAI verification center.
- Four workspace skins, light and dark appearance, code copying, and browser favicons.
- Scrollable model catalogs and stable certificate-backed signing for local service builds.

## Beta notes

- The NearAI preset currently uses its staging service. Availability depends on the configured Provider.
- This is a prerelease; features and behavior may change during beta testing.
- Beta packages are downloaded from the Releases page. The app's Check for Updates action follows the stable channel, which becomes available with the first stable release.
- Report reproducible problems through GitHub Issues. Include the app version, macOS version, and reproduction steps; remove keys, launch URLs, and private conversation content from diagnostics.
