# Cove 0.1.0-beta.4

The fourth public beta adds local message search, protects unsent drafts during navigation, preserves comparison choices in Markdown exports, and offers an explicit beta-update check.

## Download and install

- Requires an Apple Silicon Mac and macOS 13 or later. Intel Macs are not supported by this package.
- Download `Cove-0.1.0-beta.4-arm64.dmg`, open it, and drag `Cove.app` to Applications.
- Quit Cove before replacing an earlier app, then launch Cove from Applications and reopen Chat from the Launcher.
- The published package is Developer ID signed and Apple notarized. A SHA-256 checksum accompanies the download; detached publisher signatures are added after publication.
- This is build `4`, with marketing version `0.1.0`. Existing history, attachments, settings, and Provider Profiles are migrated in place. Provider Keys continue to use macOS Keychain.

See the [user guide](../user-guide.md) for setup and daily use, and the [release-signature instructions](../releasing.md#detached-release-signatures) for verifying published downloads.

## New in this beta

- Search saved user and assistant text as well as conversation titles, including Unicode content. Results show an excerpt and open the matching turn; archived searches follow archive-time ordering. Restoring an active response preserves the search position.
- Use a local trigram index for queries of at least three characters. Search does not contact a Provider, and open results refresh as new answers are saved. One/two-character searches remain supported through a local scan.
- Confirm before discarding unsent text or attachments when switching conversations, changing archive views, or starting a new chat from the Chat Surface or Launcher. Stay preserves the draft. Cancellation failure prevents navigation, and pending new-chat or archive requests block edits until they finish.
- Export comparison turns with their Selected Answer, Provider/model details, explicit skipped or unresolved state, and all saved attempts, including older retries. Labels describe saved state at export time and do not rewrite later Context Snapshots.
- Choose **Check for Beta Updates** in the Launcher to discover newer beta, release-candidate, or final releases. Version ordering handles numeric prerelease identifiers; failed checks offer the official Releases page. The stable check continues to use the stable channel, and neither action installs updates.
- Keep Browser Session credentials in per-tab, origin-scoped storage and explicit request headers instead of host-wide cookies. Validate model targets against current catalogs and preserve Private TEE requirements during retries. Improve Provider connection updates, credential replacement, and generation/stream handling.
- Clarify Provider onboarding, Active Model Set controls, source startup, and upgrade documentation. Published download files receive detached publisher signatures after release.

## Compatibility and beta notes

- The first launch upgrades the local database to SQLite schema 16 and builds the search index for existing history. Earlier builds cannot open the upgraded database. For rollback, quit Cove and retain a backup of the data directory before upgrading; a database backup does not include Keychain credentials.
- Search remains local and returns up to 50 matching conversations per query. Queries are limited to 256 Unicode characters and a three-second deadline; refine broad or short queries on larger histories.
- Restarting the Local Service invalidates Browser Sessions. Reopen Chat from the Launcher after an upgrade rather than reusing an old launch URL. Multiple-tab coordination remains outside the current feature set.
- Drafts remain in memory. Navigation confirmation protects unsent work but does not save drafts across application termination or a browser crash.
- File chat continues to support up to four text, code, or text-based PDF files per turn, each at most 4 MiB. Scanned-only PDFs require OCR first. Original files stay out of conversation exports.
- Local history, search index terms, original files, and extracted text remain unencrypted in the local database. Prompts and selected context go to the chosen Provider. Citations aid navigation and do not verify factual accuracy.
- Signing-identity changes can require one-time Keychain authorization. Restart Cove after changing an existing Provider Key outside the running service.
- The interface is English. Messages, titles, and prompts support Unicode content. The NearAI preset uses its staging service; availability and verification support depend on the model and Provider.
- Report reproducible problems through [GitHub Issues](https://github.com/tokenfunplus/cove/issues) or the [Cove Discord community](https://discord.gg/7jdddhG8ZG). Remove credentials, launch URLs, and private content from diagnostics.
