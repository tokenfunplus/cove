# Cove 0.1.0-beta.3

The third public beta adds Focus mode, a conversation timeline with bookmark previews, and a more useful native menu-bar Launcher.

## Download and install

- Requires an Apple Silicon Mac and macOS 13 or later. Intel Macs are not supported by this package.
- Download `Cove-0.1.0-beta.3-arm64.dmg`, open it, and drag `Cove.app` to Applications.
- Quit an earlier Cove instance before replacing the app, then launch Cove from Applications.
- The package is Developer ID signed and Apple notarized. A SHA-256 checksum accompanies the download.
- This is build `3`, with marketing version `0.1.0`. Existing Cove history, file attachments, settings, and Provider configuration are retained. Provider Keys continue to use macOS Keychain.

See the [user guide](../user-guide.md) for setup and daily use.

## New in this beta

- Enter Focus from the four-corner button beside Model comparison. Hide the sidebar, compact the header and composer, and expand the response area. Exit Focus or Escape restores the prior layout without losing drafts, attachments, model selections, or active responses.
- Keep model identity visible while reading long comparisons. Multiline drafts grow within a compact input area; Jump to latest stays above the actual composer and context-choice controls.
- Navigate the right-hand conversation timeline. A longer, darker marker follows the reading position; hover or keyboard-focus a marker for its prompt and a short answer excerpt. The preview remains open while moving into its controls.
- Save and remove bookmarks from timeline previews. Click a marker or Jump to turn to navigate, including on narrow screens and in Focus mode.
- Use authenticated New Chat and Settings shortcuts from the Launcher. Optional Launch at Login and the Control-Option-Space shortcut remain off until enabled.
- Find grouped troubleshooting actions, private diagnostic summaries, and a version item that opens the matching GitHub Release, including beta versions.
- Render the menu-bar wave mark through AppKit, with a system-symbol fallback if the packaged image is unavailable.
- Refresh the x/sys dependency and expand repository security checks with CodeQL, OpenSSF Scorecard, and active fuzzing.

## Compatibility and beta notes

- Timeline bookmarks store message identifiers only in the current browser profile for the Local Service address. They survive reloads but are not included in database backups or conversation exports. Clearing browser data removes them; unavailable storage limits changes to the current session.
- Focus is presentation state for the current page. It does not change Provider context, answer-selection requirements, or generation commands. Escape closes an open preview or dialog before leaving Focus; input-method composition is preserved.
- SQLite schema 14 preserves earlier history. This beta does not change the conversation storage format.
- File chat continues to support up to four text, code, or text-based PDF files per turn, each at most 4 MiB. Scanned-only PDFs require OCR first. See the user guide for extraction and context limits.
- Local history, original files, and extracted text remain unencrypted in the local database. Prompts and selected context go to the chosen Provider; citations navigate sources and do not verify factual accuracy.
- Switching signing identities can still require one-time macOS Keychain authorization. Restart Cove after changing an existing Provider Key outside the running service.
- The interface is English. Messages, titles, and prompts support Unicode content. The NearAI preset uses its staging service; availability and verification support depend on the model and Provider.
- Download beta updates from GitHub Releases. Check for Updates follows the stable channel, which becomes available with the first stable release.
- Report reproducible problems through GitHub Issues or the [Cove Discord community](https://discord.gg/7jdddhG8ZG). Remove credentials, launch URLs, and private content from diagnostics.
