# Cove 0.1.0-beta.11

Beta 11 adds download connection settings and improves access to the macOS Quick Panel. The optional global shortcut is now **Control-Option-C**.

## Download models without terminal setup

- Open **Settings > Network** to choose **System proxy**, **Manual proxy**, or **Direct connection** for chat, document search, and speech model downloads.
- Manual mode supports HTTP, HTTPS, and SOCKS5 addresses with a host and port. Proxy usernames and passwords are not supported.
- System mode follows macOS proxy and PAC settings, tries listed routes in order after connection failures, and uses a direct fallback only when the system explicitly lists DIRECT.
- **Test connection** checks the fixed Hugging Face and GitHub sources without installing a model or saving the draft. Response-body consumption is limited across redirects.
- Save settings, then retry a failed download. New settings apply to the next download or retry without restarting Cove; active downloads retain their configured client. Interrupted downloads keep validated resume and checksum checks.
- Failed model downloads link directly to **Network settings…**. Invalid proxy addresses are identified and associated with their input for assistive technology.

These settings affect model files only. Local service and inference worker traffic remain direct; Provider inference, Web Research, webpage reading, and app update routing retain their existing behavior. See [download connections](../configuration.md#model-download-connections).

## Quick Panel access and focus

- **Open Quick Panel** brings the window forward after the menu action returns, recovers its position on the pointer's display, and supports other apps' full-screen and Stage Manager spaces.
- Dismissing the panel returns focus to the previously active app when appropriate. Another visible Cove window keeps focus, and a newly active external app is left alone.
- Enable **Launcher Settings > Quick Panel Shortcut: ⌃⌥C**, then press **Control-Option-C** without Shift. The previous enabled or disabled preference is preserved; new installations keep the shortcut off until enabled.
- Hidden settings panels keep their drafts while being excluded from keyboard and assistive navigation.

See the [Quick Panel guide](../user-guide.md#use-the-quick-panel).

## Download and upgrade

- Requires an Apple Silicon Mac with macOS 13 or later. Local inference and speech require macOS 13.3 or later.
- Download `Cove-0.1.0-beta.11-arm64.dmg`. Quit Cove, open the disk image, drag Cove to Applications, and relaunch it.
- This is build `11`, with marketing version `0.1.0`. Beta 11 retains SQLite schema 27 and macOS Keychain for credentials; no database migration is required for this release.
- Download connection preferences are private machine settings stored separately from conversation exports and database backups.
- Choose **Check for Updates > Check Beta Releases…** to discover this prerelease. Verify the download using its SHA-256 checksum and [detached publisher signatures](../releasing.md#detached-release-signatures).
