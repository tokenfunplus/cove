# Cove 0.1.0-beta.8

The eighth public beta adds opt-in Web search and saved webpage evidence, with per-model request limits and references you can inspect. It also simplifies search setup, the composer toolbar, Launcher recovery, and drag-to-Applications installation.

## Download and install

- Requires an Apple Silicon Mac and macOS 13 or later.
- Download `Cove-0.1.0-beta.8-arm64.dmg`, quit Cove, open the DMG, and drag `Cove.app` to Applications before relaunching. The disk image includes an Applications shortcut and an installation background.
- SHA-256 checksums accompany release downloads; detached publisher signatures are added after publication. Refer to the release page for the package's Apple signing and notarization status.
- This is build `8`, with marketing version `0.1.0`. Existing history, attachments, settings, and Provider Profiles migrate in place. Model and search API keys use macOS Keychain.

See the [user guide](../user-guide.md#let-a-model-search-the-web), [configuration reference](../configuration.md#web-search), [privacy model](../privacy.md#automatic-web-search), and [signature verification instructions](../releasing.md#detached-release-signatures).

## New in this beta

- Turn on the globe in a conversation to let compatible models search when needed. New conversations start with search off. If a search service is missing, Cove opens Settings and preserves your draft; saving a configured default enables the initiating conversation.
- Configure Tavily, Linkup, or Exa independently of your model Provider. New and replacement keys are tested before saving; failed validation retains the previous usable key. Choose standard/deep search and optional domain filters.
- Set per-model search and page-read limits. Defaults allow three search requests, five page reads, five results per search, eight total tool calls, and a ninety-second web phase. Search failures and usage remain visible in each answer's research record.
- Open a public webpage explicitly from the composer's link icon. Preview the extracted text before submitting it as a source, sharing the existing four-source limit with uploaded files.
- Follow inline citations and the References list to saved source sections or the original website. Search excerpts are labelled separately from retrieved pages. Saved evidence follows answer selections, retries, conversation branches, downloads, and Markdown/JSON exports.
- Use native model tools with ordinary chat and Model Comparison. NearAI verifies each intermediate tool request before executing external research and retains the final answer's own verification receipt.

## Interface and Launcher improvements

- Search settings groups connection details and common limits, with advanced parameters folded by default. Custom selectors, numeric steppers, keyboard navigation, and mobile/dark layouts replace operating-system menus and number controls in the research flow.
- Attachment, webpage, and context actions share a compact composer icon toolbar with themed hover and keyboard hints. Saving feedback stays beside the settings actions.
- The Launcher groups infrequent actions, keeps login-item launches quiet, and exposes recovery and Provider setup directly when needed. About Cove links to the installed version's release notes, and discovered updates remain available in the menu.
- App packages use a consistent DMG icon layout with a Retina installation background and an Applications shortcut.

## Compatibility and operating notes

- SQLite upgrades from schema `21` to `22` for search settings, immutable attempt policies, tool traces, and saved evidence. Older builds cannot open the upgraded database. Keep a compatible backup before upgrading if you need to downgrade; database backups do not include Keychain credentials.
- Limits apply to each model attempt. Four models can make twelve searches with defaults; retries start independent budgets. Failed requests count, cache hits do not, and the selected service is not silently replaced after an error. Provider billing can consume multiple credits per request, so request counts are not a monetary spending cap.
- Search queries go to the selected search service, page reads contact source websites, and extracted text goes to your model. These requests occur outside NearAI encrypted inference. Model verification and a resolvable citation do not establish the truth of external claims.
- Web search requires compatible native tool calling. Continuous Debate and answer-tool side conversations do not inherit the main conversation toggle. JavaScript rendering, authenticated pages, and private-network URLs are not supported.
- Stop cancels active web requests. The overall Generation deadline still applies, and exhausted tool budgets require the model to finish using available evidence and identify remaining gaps.
- Local history and source snapshots remain unencrypted in SQLite. The interface is English and supports Unicode user content. Reopen Chat from the Launcher after upgrading for a new Browser Session. NearAI continues to use its staging endpoint.
- **Check for Updates** stays on the stable channel. **Check for Beta Updates** explicitly discovers eligible prereleases; neither action installs an update.

Report reproducible issues through [GitHub Issues](https://github.com/tokenfunplus/cove/issues), removing credentials, launch URLs, and personal conversation data.
