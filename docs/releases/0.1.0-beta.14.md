# Cove 0.1.0-beta.14

Beta 14 adds cloud and local Provider presets, three more managed local chat models, and the NearAI production connection.

## Choose a Provider preset

- Open **Settings > Provider settings**, create a new Provider, and choose OpenRouter, OpenAI, MiniMax, Ollama, or LM Studio. Cove fills in the endpoint and authentication defaults; you can edit the connection before testing and saving it.
- Start Ollama or LM Studio and load a model in that application first. Their loopback presets require no placeholder Key. Select Bearer if your local server requires a token.
- Cloud presets use ordinary compatible inference. NearAI retains its separate encryption and verification flow. User-managed local servers remain separate from Cove's managed models and its **Only on this Mac** policy.
- Connection tests check Provider-specific access. Rejected MiniMax responses cannot replace a working Key, including when the server reports an error inside an HTTP-success response.

## Install more local chat models

- Discover now offers Qwen2.5 1.5B Instruct and Qwen2.5 Coder 1.5B Instruct at about 1.12 GB each, and text-only Gemma 3 1B IT at about 806 MB. Each uses Q4_K_M weights from a pinned source with SHA-256 verification.
- Install a model explicitly, then choose it for a chat. Existing Qwen2.5 0.5B and Qwen3 0.6B Abliterated installations remain independently selectable.
- Discover defaults to files up to 1.5 GB and retains smaller size filters. Download size is separate from parameter count and working memory. These small models remain experimental; basic smoke checks do not establish general Chinese-language or coding quality.

See the [local model catalog](https://github.com/tokenfunplus/cove/blob/v0.1.0-beta.14/docs/local-model-catalog.md) and [Provider configuration](https://github.com/tokenfunplus/cove/blob/v0.1.0-beta.14/docs/configuration.md#provider-profiles).

## NearAI production and compatibility

- The fixed NearAI preset now uses `https://cloud-api.near.ai`. Existing staging presets retain their identity, model selection, and credential reference while resolving to production. Use **Test connection** to check the saved Key and selected model there.
- Custom staging connections and historical response snapshots retain their original destinations. A configured connection does not establish successful production authentication or verification.
- This release retains SQLite schema 29. Before returning to an older build, use the current build to remove saved None-authentication connections and NearAI presets saved with the production origin. Older readers can fail to list all Providers when either record is present. Removing a Provider also removes its Key; retain access through the Provider's account before removal. Conversation history remains local and unchanged.

## Download and upgrade

- Requires an Apple Silicon Mac with macOS 13 or later. Local inference and speech require macOS 13.3 or later.
- Download `Cove-0.1.0-beta.14-arm64.dmg`. Quit Cove, open the disk image, drag Cove to Applications, and relaunch it.
- This is build `14`, with marketing version `0.1.0`. Quit Cove and back up your data before upgrading if you plan to downgrade later.
- Choose **Check for Updates > Check Beta Releases…** to discover this prerelease. Verify the download using its SHA-256 checksum and [detached publisher signatures](https://github.com/tokenfunplus/cove/blob/v0.1.0-beta.14/docs/releasing.md#detached-release-signatures).
