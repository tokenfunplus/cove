# Cove 0.1.0-beta.9

The ninth public beta adds downloadable local chat, document search, and English/Chinese speech, with Projects for reusable context. Installed models work offline, and local processing remains an explicit choice beside configured Providers.

## Download and install

- Requires an Apple Silicon Mac and macOS 13 or later. Local inference and speech require macOS 13.3 or later.
- Download `Cove-0.1.0-beta.9-arm64.dmg`, quit Cove, open the disk image, and drag `Cove.app` to Applications before relaunching.
- SHA-256 checksums accompany the download; detached publisher signatures are added after publication. Refer to the release page for the package's Apple signing and notarization status.
- This is build `9`, with marketing version `0.1.0`. Existing history, attachments, settings, and Provider Profiles migrate in place. Provider and search credentials remain in macOS Keychain.

## Models and tools on this Mac

- Open **Settings > On this Mac > Discover** to browse 31 small-model artifact sets across eleven uses. Integrated capabilities have installation actions; explore-only entries remain source references and do not imply Cove can run them.
- Download BGE Small Chinese v1.5 for local document search, Qwen2.5 0.5B Instruct for local chat, or Qwen3 0.6B Abliterated Q5_K_M as a separate experimental chat choice. Downloads use pinned sources, declared file sizes, and SHA-256 verification.
- Import documents explicitly, select which documents to search, inspect original sections, and attach chosen results to a chat. Local search does not send the chat draft. Citations return to saved source sections and do not establish factual accuracy.
- Select **On this Mac** in the model selector to answer locally. The composer identifies processing destinations. **Only on this Mac** suppresses Web Research and rejects remote targets, including retries of older remote answers.
- Installation needs internet access; installed inference, indexing, search, and speech have no cloud fallback. Model weights are separate downloads and need additional disk space and working memory. Small chat models remain experimental: check their facts, code, and citations.

## Read answers and Debate turns aloud

- Install any of five speech bundles: **Kokoro 82M v1.0** (English), **Kokoro 82M v1.1** (Chinese/English), **Kitten TTS Nano 0.8 INT8** (English), **MeloTTS** (Chinese/English), or **Pocket TTS 18M** (English preset voices).
- Choose automatic English/Chinese routing or a manual model in **On this Mac > Speech**. Save per-model voice and speed preferences, preview a voice, and configure supported options without changing the chat model.
- Use the sound icon below a saved answer, or select a passage to read. Playback offers Pause, Resume, Stop, and WAV export. Missing models lead directly to Discover while preserving the draft.
- Enable the sound toggle beside Debate controls to read new participant turns sequentially. Listening and generation have separate pause controls; navigation, stopping, or manual playback clears automatic reading.
- Hidden reasoning and citation markers are excluded from reading. Code is skipped by default. Speech is bounded to 6,000 normalized characters, with private session-owned temporary audio and explicit export. Pocket playback speed does not alter the exported WAV.

## Projects and interface

- Create Projects with reusable instructions, background, and fixed file or webpage materials. Project creation and navigation have a dedicated directory; global New chat stays ungrouped.
- Choose **Always include** or **Search when needed** for each material. Search-only materials enter a turn only through explicitly selected passages. Each turn retains an immutable Project context snapshot for comparisons, retries, and branches.
- Discover separates installed capabilities, integrated downloads, and explore-only candidates, with task, language, size, and integration filters.
- Shared custom controls replace native selectors, checkboxes, number controls, and disclosure widgets across Chat, Debate, Projects, and settings. Focus keeps a compact composer; attachment and context actions remain available under Tools.

## Reliability and compatibility

- Keep loopback commands active when the Mac is offline, including opening local chat, selecting models, sending, and stopping.
- Use private Unix-socket inference connections and bounded embedding requests. Recheck the exact installed chat target before admitting generation or retry.
- Scope prepared-source invalidation to the changed Project material. Preserve inherited branch attachments, pending settings edits, playback speed across passages, and retryable audio cleanup.
- SQLite upgrades from beta.8 schema `22` through schema `27` for Projects, local document indexes, material usage, and speech preferences. Earlier versions cannot open the upgraded database. Quit Cove and keep a compatible data-directory backup before upgrading if you need a rollback path; Keychain credentials are separate.
- Clearing chat data also clears the local document library and indexes, while retaining downloaded model weights and live Project configuration/materials. Removing a library document does not erase copies already saved in conversations. Removing a model keeps saved answers and preferences.
- Local history and source snapshots remain unencrypted on disk. Cloud Providers still receive the prompt and selected context when chosen. Local processing is separate from NearAI encrypted inference and its response verification.
- The interface is English and supports Unicode user content. Reopen Chat from the Launcher after upgrading. **Check for Beta Updates** discovers eligible prereleases; **Check for Updates** stays on the stable channel. Neither action installs an update.
