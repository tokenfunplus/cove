# Cove 0.1.0-beta.5

The fifth public beta adds answer follow-ups and a working editor, richer model selection, separate collapsible reasoning, and locally rendered equations. It also improves response details, reading stability, and editing a saved prompt into an independent conversation.

## Download and install

- Requires an Apple Silicon Mac and macOS 13 or later. Intel Macs are not supported by this package.
- Download `Cove-0.1.0-beta.5-arm64.dmg`, open it, and drag `Cove.app` to Applications.
- Quit Cove before replacing an earlier app, then launch Cove from Applications and reopen Chat from the Launcher.
- The published package is Developer ID signed and Apple notarized. A SHA-256 checksum accompanies the download; detached publisher signatures are added after publication.
- This is build `5`, with marketing version `0.1.0`. Existing history, attachments, settings, and Provider Profiles are migrated in place. Provider Keys continue to use macOS Keychain.

See the [user guide](../user-guide.md) for setup, the [privacy model](../privacy.md) for trust boundaries, and [release signatures](../releasing.md#detached-release-signatures) for verifying downloads.

## New in this beta

- Select a passage in a saved answer and use **Ask about this** to open a separate local Side Conversation. Only the chosen passage and question enter its initial request; the original conversation remains unchanged.
- Use **Edit in workbench** for a window-local Working Draft with manual editing, undo/redo, preview, change review, clipboard copy, and Markdown download. Ask the current models to revise the whole draft or a selection, then explicitly review and apply a proposed change. Unsent instructions and changed drafts receive replacement protection.
- Read Provider-declared reasoning separately from the final answer. Reasoning opens while streaming, collapses when streaming finishes, and remains separately available in saved history and exports. It stays out of later Selected Answer context. Unmarked historical prose is not reclassified.
- Choose models with local brand icons and optional Provider-advertised names, prices, context/output limits, and capabilities. Favorites, recent choices, capability/context/price filters, and saved model combinations reduce repeated setup. Model filter menus now follow the workspace theme and support keyboard focus and nested Escape behavior.
- Open **Response details** for observed timings, Provider-reported token usage, optional estimates from manually entered rates, the immutable Provider Snapshot, and verification reports. Failed verification remains visible in the answer header. Missing measurements remain unavailable rather than zero.
- Keep the reading position while reasoning folds or streamed layout changes. **Jump to latest** shows how many replies gained text while following was paused. Generation stages show elapsed time and applicable stop/recovery controls.
- Edit a saved terminal prompt and resend selected models in a new Conversation Branch. Its inherited history uses the source turn's exact saved Selected Answer context and original attachments; current generation settings apply to the new request. Loading and cancellation failures retain ownership of accepted work.
- Read inline and display LaTeX, aligned equations, matrices, and long expressions using locally bundled KaTeX and fonts. Code, currency, escaped delimiters, and unsupported formulas remain readable. Long formulas scroll within comparison cards. No remote typesetting service is added. Resolves [#25](https://github.com/tokenfunplus/cove/issues/25).
- Preserve failed/stopped revision results, partial token usage, saved verification outcomes, reasoning-only terminal notices, and recorded metrics across asynchronous transitions. Clear chat data blocks new Answer tools work until deletion completes.

## Compatibility and beta notes

- First launch migrates a schema 16 database through schema 19 for optional Generation Metrics, structured reasoning, and branch provenance. Earlier builds cannot open the upgraded database. Quit Cove and retain a backup of the data directory before upgrading if rollback may be needed; database backups do not contain Keychain credentials.
- Branches own independent copies of selected history and source files. Deleting the source conversation does not remove a branch's retained copies. Copied verification records describe their original responses and are not newly verified by copying.
- Working Drafts and unsent instructions remain in window memory and are lost on refresh, termination, or a browser crash. Download important drafts explicitly. Side questions and model revision requests/results use normal local Conversation History.
- Model catalog details are Provider-advertised and optional. Icons do not establish privacy or verification properties. Prices entered for estimates are browser-local preferences and do not represent a billing guarantee. Catalog capabilities do not necessarily mean Cove exposes every corresponding feature.
- Raw formula and message source remains authoritative for storage, Provider context, copying, and exports. Typesetting is bounded, trust-requiring TeX commands are denied, and the existing Content Security Policy is retained.
- Build/test dependencies use conservative local picomatch and bundled Rollup parser patches for GHSA-fc5q-39xc-vjpf. The audit gate verifies exact installed patch contents before recognizing that advisory revision; raw registry audit still reports the affected published version. Complex repeated-extglob filters are intentionally restricted. See [dependency patch maintenance](../dependency-patches.md). The previously documented low-severity SDK elliptic advisory remains.
- Local history, original files, and extracted text remain unencrypted in SQLite. Selected content goes to the chosen Provider. The NearAI preset continues to use its staging service; availability and verification support depend on the Provider/model and explicit check results.
- Restarting the Local Service invalidates Browser Sessions. Reopen Chat from the Launcher after upgrading. Signing changes can require a one-time Keychain authorization; restart Cove after changing an existing Provider Key outside the service.
- **Check for Updates** follows the stable channel. **Check for Beta Updates** explicitly discovers newer betas, release candidates, or final releases; neither action installs an update.
- The interface is English; messages, titles, and prompts support Unicode. Report reproducible issues through [GitHub Issues](https://github.com/tokenfunplus/cove/issues), removing credentials, launch URLs, and personal content from diagnostics.
