# Cove 0.1.0-beta.7

The seventh public beta adds cited Debate stage summaries, cumulative usage and budget controls, and configurable pacing. It also makes Debate and Focus layouts more compact and fixes Provider connection validation and summary recovery.

## Download and install

- Requires an Apple Silicon Mac and macOS 13 or later.
- Download `Cove-0.1.0-beta.7-arm64.dmg`, quit Cove, open the DMG, and drag `Cove.app` to Applications before relaunching.
- The published package is Developer ID signed and Apple notarized. A SHA-256 checksum accompanies the download; detached publisher signatures are added after publication.
- This is build `7`, with marketing version `0.1.0`. Existing history, attachments, settings, and Provider Profiles migrate in place. Provider Keys continue to use macOS Keychain.

See the [Debate guide](../debate.md), [configuration reference](../configuration.md), [privacy model](../privacy.md), and [signature verification instructions](../releasing.md#detached-release-signatures).

## New in this beta

- Create stage summaries of new ideas, supported position changes, and open questions, with links to original turns. Choose a participating model and a cadence of one to ten rounds, or turn summaries off. New setup defaults to every three completed rounds; existing debates retain summaries off until configured.
- View cumulative reported input/output tokens, summary calls, and optional USD estimates across the entire debate. Configure token or estimated-cost budgets, reminders, and explicit automatic pause through **Budget & pace**.
- Set a zero-to-sixty-second interval between turns. Summary, budget, rate, and pacing changes apply before further calls without starting inference.
- Read more of the transcript in compact standard and Focus workspaces. The topic appears once, workspace actions share a toolbar, and the intervention field starts on one line and grows with its draft. The live brief uses shorter attributed previews.

## Reliability improvements

- NearAI key tests authenticate before consulting the public model catalog, which can return successfully for rejected credentials. Metadata-only saves retain the previous connection-test status.
- Provider settings follow the active connection, including delayed profile loading, and preserve manually selected drafts during profile refreshes. In-flight commands finish before the editor changes targets.
- The canonical Debate topic remains visible when its Conversation History title is renamed. **New debate** is available in Focus, and sidebar-width changes resize a wrapping intervention draft.
- A rejected browser claim clears its persisted usage marker so restart recovery does not invent a model call or missing usage.
- A summary the browser never claimed remains due after Resume. Settled paid summary attempts are not retried automatically. Completed responses with invalid citations remain available in Details without becoming a parsed stage summary; failed verification still discards the response.

## Compatibility and operating notes

- SQLite migrates to schema `21` for persisted summary and budget controls. Older releases cannot open an upgraded database; preserve a compatible backup if you plan to downgrade.
- Summaries make additional model calls and count toward usage. They are generated interpretations of attributed statements, not evidence that the interpretation is correct, and they do not enter later participant context.
- Budget checks run before further calls. Active requests, including concurrent openings, can exceed a threshold. Estimates use saved rates and reported usage; missing counts and prices remain unavailable or partial. Automatic pause is an explicit setting, not a Provider-side billing cap.
- NearAI participation requires the Debate page to remain open for browser encryption and verification. The preset continues to use its staging endpoint. Restart leaves debates paused and requires explicit Resume.
- Local history and attachments remain unencrypted in SQLite. The interface is English, and user messages and topics support Unicode. Reopen Chat from the Launcher after upgrading to obtain a new Browser Session.
- **Check for Updates** stays on the stable channel. **Check for Beta Updates** explicitly discovers eligible prereleases; neither action installs an update.

Report reproducible issues through [GitHub Issues](https://github.com/tokenfunplus/cove/issues), removing credentials, launch URLs, and personal conversation data.
